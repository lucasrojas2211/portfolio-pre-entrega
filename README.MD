# SYS.LUCAS_ROJAS // Portfolio Personal v1.0

## 📁 Propósito del Proyecto
Este repositorio contiene la primera versión de mi portfolio digital, desarrollado como entrega de proyecto integrador para el curso de Front-End. 

Más allá de cumplir con los requisitos académicos, esta plataforma está diseñada bajo una estética "Dark Deco" y neo-brutalista inspirada en interfaces de terminal, con el objetivo de exhibir de forma centralizada mi perfil multidisciplinario. El proyecto funciona como un ecosistema que unifica mis tres áreas principales de desarrollo profesional:

1. **Interfaces UX/UI & Frontend:** Diseño de sistemas, flujos de usuario, accesibilidad web y maquetación de interfaces escalables (con experiencia aplicada en sistemas de gestión estatales).
2. **Media Visuals & Diseño Multimedial:** Exploración audiovisual, motion graphics y desarrollo conceptual para instalaciones interactivas.
3. **B-Side / Live Set & Hardware:** Producción de música electrónica (bajo el proyecto *unqonou*), curaduría musical (Music Selector) y provisión de equipamiento de audio activo para eventos.

## 🛠️ Tecnologías Utilizadas
La arquitectura de esta iteración prioriza el rendimiento y la semántica, utilizando tecnologías nativas sin frameworks de terceros:

* **HTML5 Semántico:** Estructuración lógica con etiquetas modernas (`<header>`, `<main>`, `<section>`, `<article>`).
* **CSS3 Avanzado:** 
  * Sistema de grillas con **CSS Grid** y **Flexbox** para diseño modular y responsivo.
  * Efectos de *Glassmorphism* (`backdrop-filter`) y posicionamiento complejo (`position: fixed`, `absolute`).
  * Integración optimizada de Google Fonts (Space Grotesk, Lora).
* **Media Queries:** Adaptabilidad total a dispositivos móviles y *Responsive Design*.
* **Formspree API:** Integración de backend as a service para el procesamiento y envío seguro de formularios de contacto.
